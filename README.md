# Semantic Decision Infrastructure (SDI)

**Author:** Nelson Chou (周端政)
**Status:** Public Concept (definition and conceptual structure)
**Definition version:** SDI v1.0 (2026-02-05)
**Primary definition:** https://www.nelsonchou.com/expertise/professional-modules/semantic-decision-infrastructure/

## Authoritative definition

Authoritative definition: the "Definition" section published on NelsonChou.com on 2026-02-05. Where other sentences on the definition page, in structured data, or elsewhere describe SDI in different words, that section is the reference.

**Semantic Decision Infrastructure (SDI)** — SDI is a structure of definitions, classifications, judgment criteria, and references that people and machines can use together. It establishes a stable default for judgment within a particular concept or domain, while remaining available for continued citation, versioning, and correction.

繁體中文正式名稱：語意判斷基礎設施。日本語：語意判断基盤。

## Core claim

SDI is a structural system that enables people and AI, when choosing, comparing, or interpreting, to adopt and cite a specific semantic baseline as their default reference.

## Conceptual structure

Four core components, as named on the definition page:

- **Judgment Baseline** — definitions, classifications, and judgment criteria that can be cited.
- **Citable Structure** — reference pathways that allow people and AI to return to the same basis of understanding when answering or comparing.
- **Versioning** — definitions can change, but revisions must remain traceable and comparable.
- **Canonical Anchor** — the authoritative source URL for a concept agrees with its structured data.

Conceptual path: Human-readable → Machine-readable → Reusable → Citable → Decision Support.

Scope (condensed from the definition page): SDI applies to brands, professional practices, and methodologies that need to be understood and compared accurately, and whose core assets are long-term trust and the weight their judgment carries.

## Non-goals

- SDI is not SEO tactics: ranking techniques are not its core.
- SDI is not content marketing volume: mass publication is not its objective.
- SDI is not advertising or retargeting: exposure and conversion are not its primary objectives.

## Relationship to other concepts

- Nelson Amplification Law (NAL): the definition page notes that judgment amplified by machines must withstand scrutiny, which is the concern of NAL.
- Semantic Defense Engineering: the definition page describes it as an implementation view that operationalises parts of the SDI governance layer; it is not a substitute for the SDI definition.

## Scope of this repository

This repository is a public concept record: name, author, the authoritative definition, the core claim, the four core components, the conceptual path, the condensed scope, the non-goals, the two conceptual relationships, version history and citation entry point. Implementation checks, evaluation frameworks, audit procedures and any method for building or maintaining an SDI are outside this record and are not fixed by it. The full text and multilingual versions live on the primary definition page. This repository does not mirror that content.
